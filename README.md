# Two-Sentence Horror

A horror story in exactly two sentences. A smartwatch keeps logging its
owner's heart rate as zero every night, and the app keeps dismissing it as a
sensor error — until one night it stops dismissing it.

`main.py` writes the story to `/output/entry.txt`.
